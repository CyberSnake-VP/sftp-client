# **SFTP Client**

Консольное Java-приложение для работы с **SFTP** сервером.

Проект разработан в рамках тестового задания и состоит из двух независимых Maven-проектов:

- *sftp-client* — консольное приложение;

- *sftp-client-tests* — проект автоматизированных тестов на TestNG.



**Функциональность:**

- подключение к SFTP серверу;
- получение списка доменов и IP адресов;
- поиск IP по домену;
- поиск домена по IP;
- добавление новой пары "домен – IP-адрес";
- удаление пары "домен – IP-адрес" по домену или IP;
- загрузка обновленного JSON файла на сервер.

### Структура тестового проекта sftp-client-solution/:

```text
sftp-client-solution/
├── artifacts/
│   ├── sftp-client-1.0-jar-with-dependencies.jar
│   ├── sftp-client-tests-1.0-autotests.jar
│   └── testng.xml
├── data/
```

## Инструкция по сборке проекта

### Требования

Для сборки проекта должны быть установлены:

- Java 8 или выше;
- Apache Maven 3.6+;
- Docker и Docker Compose (для запуска тестового SFTP-сервера).

### Сборка клиентского приложения

Перейдите в каталог проекта клиента:

```bash
cd sftp-client
```

Выполните команду:

```bash
mvn clean package
```

После успешной сборки исполняемый JAR-файл будет находиться в каталоге

```bash
target/sftp-client-1.0-jar-with-dependencies.jar
```

### Сборка проекта с автотестами

Перейдите в каталог проекта автотестов

```bash
cd sftp-client-tests
```

Выполните команду :

```bash
mvn clean package
```

После успешной сборки исполняемый JAR-файл автотестов будет находиться в каталоге

```bash
target/sftp-client-tests-1.0-autotests.jar
```

Запуск тестового SFTP-сервера

Из корневого каталога  выполните команду:

```bash
docker compose up -d
```

В архив также включены уже собранные исполняемые JAR-файлы, расположенные в каталоге artifacts:

**artifacts/**
**├── sftp-client-1.0-jar-with-dependencies.jar**
**├── sftp-client-tests-1.0-autotests.jar**
**└── testng.xml**

Поэтому для запуска приложения и автотестов повторная сборка проекта не требуется.

## Инструкция по работе с приложением

### 1. Запуск тестового SFTP-сервера

Перед запуском клиента необходимо запустить тестовый SFTP-сервер.

Из корневого каталога в котором есть файл `docker-compose.yml` выполните команду:

```bash
docker compose up -d
```

После запуска будут доступны следующие параметры подключения:

Хост: localhost
Порт: 2222
Логин: user
Пароль: pass

### 2. Запуск клиента

Перейдите в каталог **artifacts** и выполните команду:

```bash
cd artifacts
java -jar sftp-client-1.0-jar-with-dependencies.jar
```

### 3. Подключение к серверу

После запуска программа последовательно запросит параметры подключения:

**Host:**
**Port:**
**Login:**
**Password:**

Для тестового сервера необходимо указать:

- **Host:**             localhost
- **Port:**              2222
- **Login:**            user
- **Password: **   pass

После успешного подключения откроется главное меню приложения.

### 4. Главное меню

Приложение поддерживает следующие операции:

1. Получить список всех пар "домен – IP-адрес".
2. Найти IP-адрес по имени домена.
3. Найти доменное имя по IP-адресу.
4. Добавить новую пару "домен – IP-адрес".
5. Удалить запись по доменному имени или IP-адресу.
6. Завершить работу программы.

После выполнения каждой операции пользователь возвращается в главное меню до выбора пункта **0** (выход).

### Особенности работы

- Добавление записей выполняется только для уникальных доменных имён и IP-адресов.
- IP-адрес должен соответствовать формату IPv4.
- При ошибке подключения или вводе некорректных данных приложение выводит сообщение об ошибке и предлагает повторить ввод.
- Данные хранятся в JSON-файле на SFTP-сервере. Файл из каталога *data/ addresses.json*

## Инструкция по запуску автотестов

Автотесты запускаются с использованием **TestNG**.
Перед запуском необходимо, чтобы тестовый **SFTP**-сервер был доступен.

### Требования

Перед запуском автотестов необходимо:

- установить Java 8 или выше;
- запустить тестовый SFTP-сервер:

```bash
docker compose up -d
```

------

### Запуск автотестов

Перейдите в каталог `artifacts`:

```bash
cd artifacts
```

Запустите исполняемый JAR-файл:

```bash
java -jar sftp-client-tests-1.0-autotests.jar
```

После завершения выполнения TestNG выведет сводку о результатах тестирования, например:

```text
===============================================
Client Test Suite
Total tests run: 24
Passes: 24
Failures: 0
Skips: 0
===============================================
```

> **Примечание:** запуск JAR-файла необходимо выполнять из каталога `artifacts`, поскольку файл `testng.xml` находится в этом же каталоге.

## Краткое обоснование тестов

Автотесты разработаны в отдельном Maven-проекте с использованием **TestNG** и объединены в единый **Test Suite** (`testng.xml`).

Тесты разделены на две группы.

### 1. Модульные тесты (Unit tests)

Класс **AddressValidatorTest** проверяет корректность работы валидатора без обращения к SFTP-серверу.

Проверяются:

- корректность формата доменного имени;
- корректность IPv4-адреса;
- обработка пустых значений;
- обработка некорректных входных данных.

### 2. Интеграционные тесты (Integration tests)

Класс **AddressServiceTest** проверяет работу сервиса совместно с тестовым SFTP-сервером.

Проверяются:

- загрузка JSON-файла на сервер;
- получение списка записей;
- поиск IP-адреса по доменному имени;
- поиск доменного имени по IP-адресу;
- добавление новой записи;
- удаление существующей записи.

Интеграционные тесты выполняются только при доступном SFTP-сервере и позволяют убедиться в корректной работе приложения с удалённым файловым хранилищем.
